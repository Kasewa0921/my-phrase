# My Phrase

スマホを中心に使う、英会話フレーズの練習用Webアプリです。

## ローカルで使う

`index.html` をブラウザで開きます。`phrase-library.js` と `assets/` は同じフォルダ構成で配置してください。

`beginner-dialogues.js` と `workbook-scenes.js` も同じフォルダに置いてください。現在の練習教材は `workbook-scenes.js` の18場面・36のやり取りです。指定Excelの100フレーズをすべて含み、180種類の返事にはそれぞれ内容に合う先生の返事を定義しています。各場面は2往復で次の場面へ進み、チャット内の小さな区切りで切り替わります。毎回同じ共通の聞き返しや「先生はどう？」を差し込むことはしません。未編集の旧教材はランダム練習から外し、利用者が編集・追加した会話は保持します。

出題は単純なランダムではなく、表示回数の少ないフレーズを含む場面を優先します。4択もその場面に合う5候補から表示・使用回数を考慮して4つを選び、並びをランダム化します。直近3場面の繰り返しは可能な限り避けます。表示回数・使用回数は端末内の `my-phrase-practice-coverage-20261025-v1` に保存され、再度開いても引き継ぎます。日本語と英語の表示切り替えは回数に数えません。差し替え語句が異なる例文を使っても、元のフレーズIDで学習記録を更新します。

`phrase-explanations.js` に、登録100フレーズの使う場面・似た表現・使い分けと、先生側の基本表現の補足を管理しています。チャット内の赤字を500ms長押しすると、意味・使う場面・その会話の例文・似た表現を下部パネルに表示します。PCはクリック、キーボードはEnterまたはSpaceでも開けます。スクロールや短いタップでは開きません。複数に分かれた赤字も、同じ文の型全体の解説を表示します。閉じるボタン・背景・Escで会話へ戻れます。解説を開くだけでは返事や学習回数は増えません。カスタム表現など専用解説がない場合は、既存の意味と型の情報を表示し、似た表現を作り上げません。このデータファイルもHTMLと同じフォルダに配置してください。

Excelのフレーズ用の `phrase-additions.js` も必要です。一覧は指定された `日常会話フレーズ_追加100.xlsx` のNo.101〜200の100件だけで構成します。旧307件・398件の一覧には追加せず、一度だけ全件を置き換えます。「厳選100」や「最近学んだ表現」は含めません。英語が一致する項目の学習記録だけを引き継ぎ、訳・カテゴリ・例文は指定Excelを優先します。置き換え後の追加・編集・削除は再読込しても保持します。

## 機能メニューと4択トレーニング

左上のメニューから「会話練習」「4択トレーニング」「フレーズ一覧」へ移動できます。フレーズ・会話の追加も同じメニューから開けます。

4択は指定Excelの100フレーズを10セクションに分け、各10問・初期設定8秒で出題します。80%以上で次のセクションを解放し、正答率に応じてS（100%）、A（90%）、B（80%）、C（60〜70%）、D（50%以下）を表示します。問題と選択肢は毎回シャッフルします。○・×は静止表示で、「わからない」は時間切れと分けて記録します。

ゲームは `timed-quiz.html` を独立した画面として読み込みます。メニューを開く・別機能へ移る・タブを離れると一時停止し、戻った後は「続ける」で再開します。会話・フレーズの保存領域には書き込みません。成績と設定は `my-phrase-timed-quiz-v1` に保存し、同じ保存先に試作の記録がある場合だけ初回にコピーします。ローカルHTMLから公開URLへ、または別端末へ自動で移行することはありません。

`timed-quiz-prototype.html` を共通ソースとして `node scripts/build-timed-quiz.cjs` で本番用の `timed-quiz.html` を生成します。ローカル確認用の単体HTMLは `node scripts/build-timed-prototype.cjs` で別途生成し、公開対象には含めません。

## 教材とテスト

Node.jsが利用できる環境で実行します。追加パッケージは不要です。

```sh
node scripts/build-phrase-library.cjs
node scripts/build-phrase-library.cjs --check
node scripts/build-phrase-additions.cjs --check
node scripts/build-timed-prototype.cjs
node scripts/build-timed-quiz.cjs
node tests/practice.test.cjs
node tests/timed-prototype.test.cjs
node scripts/build-static.cjs
```

教材の原本は `日常英会話フレーズ300選.md`、語句と翻訳の例は `scripts/build-phrase-library.cjs` で管理します。

一覧の原本は `日常会話フレーズ_追加100.xlsx` です。Python標準ライブラリだけで `python scripts/import-phrase-workbook.py 日常会話フレーズ_追加100.xlsx` を実行し、`data/phrase-additions.json` を更新できます。`--check` を付けるとExcelとの一致だけを検証します。続いて `node scripts/build-phrase-additions.cjs` で配信用データを生成します。置き換え済みの端末内フラグは `my-phrase-workbook-replacement-20261024-v1` です。置き換え前の一覧は `my-phrase-before-workbook-replacement-20261024-v1` に退避し、通常の一覧・検索には出しません。将来別の教材に置き換える場合は、データとこのフラグを更新してください。Excel自体はGitに含めません。

## 公開

配信対象は `dist/` のアプリ本体・教材データ・アイコン画像のみです。開発資料や原本、テスト、不要な画像は配信しません。

GitHubの `main` ブランチにpushすると、GitHub Actionsで教材の整合性確認・テスト・ビルドを実行し、成功した場合だけGitHub Pagesに公開します。

## 保存について

追加・編集した内容と学習記録は、利用しているブラウザの `localStorage` に保存されます。サーバーへの同期や、スマホとPCの自動共有はまだ実装していません。

ローカルHTMLと公開URLでは保存場所が異なります。公開URLを初めて開くと初期教材から始まり、既存のローカルデータは自動では移りません。
